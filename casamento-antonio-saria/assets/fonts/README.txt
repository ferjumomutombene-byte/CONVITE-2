Este projeto usa as fontes Google Fonts "Great Vibes" e "Cormorant Garamond", carregadas diretamente
via <link> no index.html (nao e necessario guardar ficheiros de fonte aqui).

Se preferir hospedar as fontes localmente (ex: para funcionar sem internet), pode:
1. Descarregar os ficheiros .woff2 em https://fonts.google.com
2. Coloca-los nesta pasta
3. Substituir o <link> do Google Fonts por um @font-face no style.css
